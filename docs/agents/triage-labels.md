# Triage Labels

Map canonical triage roles to these `Status:` values in local tickets.

| Canonical role | Tracker value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate |
| needs-info | needs-info | Waiting on reporter information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

When a skill mentions a triage role, use its tracker value.
Edit the tracker-value column to change the vocabulary.
