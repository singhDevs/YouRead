## STANDARD MODE

**Target reading time:** ~50-60% of video length
- A 30-minute video should produce approximately a 15-18 minute read
- A 10-minute video should produce approximately a 5-6 minute read

**Approach:** Balanced condensation. Save time while preserving substance and personality.

**What to include:**
- All main arguments and core points
- Key supporting examples
- Important code with explanations
- Speaker's opinions, humor, and personality
- Relevant context and background

**What to condense:**
- Repetition (mention once, note emphasis)
- Verbose explanations (tighten the prose)
- Transitional filler
- Redundant examples (keep the best ones)

**Tone:** Natural and engaging. Preserve the speaker's voice fully. If they're funny, be funny. If they're frustrated, show frustration.

**Article structure:**
- Full introduction with context
- Well-organized body sections
- Complete Key Takeaways
