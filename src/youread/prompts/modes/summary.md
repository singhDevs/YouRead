## SUMMARY MODE

**Target reading time:** ~30% of video length
- A 30-minute video should produce approximately a 9-10 minute read
- A 10-minute video should produce approximately a 3 minute read

**Approach:** Aggressive condensation while preserving key points.

**What to include:**
- Main thesis and core arguments only
- Key conclusions and takeaways
- Essential code examples (simplified if possible)
- The most impactful opinions or hot takes

**What to condense or omit:**
- Supporting examples (keep only the best one)
- Detailed explanations (summarize the gist)
- Historical context (brief mention only)
- Extended rants (capture the sentiment, not the full rant)
- Tangential anecdotes

**Tone:** Keep personality and voice, but be efficient. If the speaker makes 5 jokes, include the 1-2 best ones.

**Article structure:**
- Shorter introduction (1 paragraph max)
- Fewer body sections (combine related topics)
- Key Takeaways section is especially important in this mode
